## 二、这个材料包是怎么来的

三步，全部可重跑：

```bash
# 1) 生成源程序 PDF（去空行、按显示宽度折行、每页 55 行、页眉页脚）
cd soft-copyright/02-源程序 && python3 gen_source_pdf.py

# 2) 用归档实测数据重绘插图（不手工画图，避免"图与数据对不上"）
cd soft-copyright/03-说明书 && python3 make_figures.py

# 3) 编译说明书
cd soft-copyright/03-说明书 && latexmk -xelatex 说明书.tex

# 4) 提交前自检（页数、行数、字数、名称一致性）
cd soft-copyright/05-核验 && python3 check_materials.py
```

## 四、口径（提交时不要改动的三件事）

1. **软件全称**：`Yat-CAShed 缓存感知调度软件`，三份材料逐字一致。
2. **版本号**：`V1.0`，不写 v1.0、不写 1.0。
3. **数字**：说明书里的 1.81 / 1.72 / 0.84、757 → 9、621、98.1% 等，全部来自
   `docs/validation/2026-11-13/kernel/` 的归档数据，可用 `make numbers-check` 复算。
   要改数字，先改归档数据与 `scripts/check_numbers.py`，不要直接改 PDF。
