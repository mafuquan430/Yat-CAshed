# P4：L2 按在线核数归一，饱和率中位数 96.6% → 0%（2026-11-22）

## 背景

`2026-11-21-crp` 的探针显示：主口径里 CRP 饱和率 96.6%（三轮：96.6 / 97.4 / 5.3）。
根因是结构——$\mathrm{recency} = L_1 + 2L_2$，而 $L_2$ 是**所有核**自本任务上次运行以来的
执行时间**之和**，核越多、负载越满，这个值越大，与任务自己的重用距离无关。

## 改动（一行语义，三行代码）

在 `yat_calculate_recency()` 里，$L_2$ 求和之后除以在线核数：

```c
if (l2_recency) {
    unsigned int n = num_online_cpus();
    if (n > 1)
        l2_recency = div_u64(l2_recency, n);
}
```

这样 $L_2$ 从"全核干扰总和"变成"平均每核干扰"，与 $L_1$（单核干扰）同量纲，
1 ms 的归一化窗口才有意义。改动在 `patches/0001` 的最终形态里（内核 #26，2879 行）。

## 结果

| 指标 | 归一化前（3 轮） | 归一化后（5 轮） |
|---|---|---|
| 饱和率中位数 | **96.6%** | **0%** |
| 饱和率全距 | 5.3% – 97.4% | 0% – 82.2% |
| 单轮值 | 96.6 / 97.4 / 5.3 | 81.2 / 0 / 0 / 0 / 82.2 |
| 成本比值 ρ（中位） | 1.81（#20 主口径） | **1.79**（[1.68, 2.07]，n=4） |

**中位数从 96.6% 打到 0%，但没有消除双峰。** 五轮里仍有两轮超过 80%。

## 怎么读

1. **归一化是对的。** 它让 CRP 在多数轮次里重新具备分辨力（`crp_sat = 0` 意味着
   每个候选核的 benefit 不再恒为 0），且成本没有变化（ρ 中位 1.79 对 1.81，在噪声内）。
2. **双峰说明还有第二个因素：窗口本身。** 1 ms 是按"单核干扰"猜的占位值，与
   200 µs 唤醒、8 任务 4 核的实际相位不匹配；哪一轮撞上，哪一轮就再次饱和。
   这一刀要按 recency 分布来定（路线 D 的下一步，原 P2）。
3. **所以 P4 是必要但不充分的一步**。它的价值在于：把"结构错误"与"参数未标定"
   这两件事分开了——分开之后，剩下的问题只有一个可调的旋钮。

## 局限

- 5 轮、QEMU/TCG，噪声大；两轮 82% 的具体触发条件没有定位（缺 recency 直方图）；
- ρ 只有 4 个有效样本（`run-3` 未产出 yat 行，计时缺失，饱和率仍在）；
- 归一化按"在线核数"而非"同 LLC 域核数"，在有多个簇的真机上仍是近似。
