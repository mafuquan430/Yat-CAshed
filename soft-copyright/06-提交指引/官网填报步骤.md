# 官网填报逐步操作（实名已通过，从这里开始）

> 适用：中国版权保护中心（CPCC）计算机软件著作权登记，个人申请人，2026 年口径。
> 系统界面文案会随版本微调，本文用「」标出**你必须点到的按钮/入口**；文字略有差异时按同义入口识别（见第 9 节）。

---

## 0. 开始前：把文件放到一个文件夹

```bash
mkdir -p ~/软著上传 && cd ~/软著上传
cp /root/LAB_ungraduate/Yat-CAshed/soft-copyright/02-源程序/源程序鉴别材料.pdf ./1-源程序鉴别材料.pdf
cp /root/LAB_ungraduate/Yat-CAshed/soft-copyright/03-说明书/说明书.pdf        ./2-说明书.pdf
cp ~/身份证正反面.pdf ./3-身份证明.pdf
# 4-签章页.pdf 在第 5 步生成、第 6 步签字扫描后再放进来
```

带序号是为了上传时不容易选错文件。

---

## 1. 登录

1. 浏览器打开 <https://register.ccopyright.com.cn>。
2. 输入实名认证时的手机号/邮箱 + 密码 + 图形验证码。
3. 点「登 录」。

---

## 2. 进入登记入口

1. 进入「用户中心」。
2. 左侧菜单找「软件著作权登记」（也可能在顶部「登记」下拉里）。
3. 点「计算机软件著作权登记申请」。
4. 点「在线登记」或「我要登记」（不同版本二选一，都是新建申请）。

---

## 3. 身份与须知

1. "办理身份"选「著作权人」。
2. 勾选「我已阅读并同意《登记申请须知》」。
3. 点「下一步」。

---

## 4. 填写申请表（核心，逐字段照抄）

### 4.1 软件信息

| 字段 | 填入 | 注意 |
|---|---|---|
| 软件全称 | `Yat-CAShed 缓存感知调度软件` | 一字不差，含中间半角空格 |
| 软件简称 | `Yat-CAShed` | 可留空 |
| 版本号 | `V1.0` | 不要写 v1.0 |
| 开发完成日期 | `2026-11-13` | 不晚于提交日 |
| 是否已发表 | 「未发表」 | 若已公开披露则选已发表并填日期 |
| 软件分类 | `系统软件` → `操作系统及其配套软件` | 两级下拉都要选 |

### 4.2 开发信息

| 字段 | 填入 |
|---|---|
| 开发方式 | `独立开发` |
| 权利取得方式 | `原始取得` |
| 权利范围 | `全部权利` |
| 编程语言 | `C、Shell、Python` |
| 源程序量 | `4800`（行） |
| 开发硬件环境 | `x86_64 计算机，4 核以上，内存 8GB 以上` |
| 运行硬件环境 | `x86_64 计算机，4 vCPU，内存 1GB 以上` |
| 开发软件环境 | `Ubuntu（WSL2）、gcc、make、QEMU 8.x、Python 3` |
| 运行软件环境 | `Linux 6.8（x86_64）` |
| 开发目的 | `在多核 Linux 上验证缓存感知的任务选核策略，并给出可复现的代价测量方法` |
| 面向行业 | `操作系统` / `教学科研`（可多选） |

### 4.3 主要功能与技术特点（500～1300 字）

1. 打开 `soft-copyright/01-申请表/申请表字段与功能描述.md`。
2. 复制"## 二、主要功能与技术特点"下的正文（从"本软件是一套运行于"到"……不取锁的空转路径。"）。
3. 粘贴到文本框。
4. 粘贴后 Ctrl+A 检查：若每行都断，删掉段内换行（系统按字符数校验，换行也占位）。
5. 页面字数提示应在 **1244** 左右（限制 500–1300）。
6. 提示超长就删"技术特点有四"的最后一点（约 60 字）。

### 4.4 著作权人信息

1. 实名信息自动带出，核对姓名与 18 位证件号。
2. 「地址」「邮编」必填。
3. 「联系人/电话/邮箱」填能收到通知的手机与常用邮箱（受理与补正都靠它）。

### 4.5 保存

点「保存草稿」。**先别提交**，签章页还没签字。

---

## 5. 生成并下载签章页

1. 申请详情页找「生成签章页」/「打印申请确认签章页」。
2. 生成后点「下载」。
3. 存为 `~/软著上传/4-签章页-待签字.pdf`。

> 按钮灰色 = 还有必填项未填，页面顶部会有红色汇总提示。

---

## 6. 打印 → 手抄 → 签字 → 扫描

1. 打印：A4 单面、黑白、缩放「实际大小 / 100%」（否则条码变形）。
2. 手抄：黑色签字笔逐字抄承诺；签名用身份证姓名；写 18 位身份证号；日期写当天。
3. 抄错重新打印，不要涂改。
4. 扫描：手机扫描 App → 300 dpi → 彩色 → 导出 PDF → 命名 `4-签章页.pdf`。
5. 细项见 [`../04-签章页/签章页-抄写说明.md`](../04-签章页/签章页-抄写说明.md)。

---

## 7. 上传材料并提交

回到申请详情页 →「材料上传」/「上传附件」：

| 上传位 | 选文件 |
|---|---|
| 源程序鉴别材料 | `1-源程序鉴别材料.pdf`（60 页） |
| 文档鉴别材料 | `2-说明书.pdf`（21 页） |
| 身份证明 | `3-身份证明.pdf`（正反面同一 PDF） |
| 申请确认签章页 | `4-签章页.pdf`（手抄+手签扫描件） |

每个位置点「上传」→ 选文件 → 等进度条走完、出现文件名。全部传完点「提交申请」→「确定」。

> 提交后状态变「已提交/待受理」，内容不能再改；要改只能等补正或撤回重报。

---

## 8. 提交后

1. 成功页显示**受理号**（形如 `2026R11...`），立刻截图。
2. 「我的申请」里状态「待受理」。
3. 1–3 个工作日后变「已受理」，可「下载受理通知书」。
4. 受理号 + 通知书截图发导师。

---

## 9. 界面不一致时的通用识别法

- 入口：找带「登记」的菜单 → 「软件著作权」→ 「新建 / 在线登记 / 我要登记」。
- 签章页：详情页右上或底部，通常叫「生成签章页」「打印签章页」「申请确认签章页」。
- 上传：详情页往下滚，标题多为「材料上传」「上传附件」「附件管理」。
- 兜底：右上角「帮助中心 / 在线客服」，或 Ctrl+F 搜「签章」「上传」。

---

## 10. 常见卡点

| 卡点 | 原因 | 处置 |
|---|---|---|
| 「提交」灰色 | 必填未填（邮编、面向行业、材料未齐） | 看页面顶部红色提示逐项补 |
| 提示"功能描述不足 500 字" | 粘贴被截断 | 全选重粘，确认末尾那句在 |
| 文件格式不支持 | 传了 docx/jpg 到 PDF 位 | 统一转 PDF |
| 上传后文件名不见了 | 超过大小限制 | 压缩 PDF 后重传 |
| 签章页被拒 | 模糊/缺角/条码不清 | 300 dpi 重扫，四角完整 |
| 状态"待补正" | 审查员要求补材料 | 30 天内补，逾期视为撤回 |

## 11. 时间与费用

- 登记费 0 元（2017 年起取消）。
- 受理 1–3 个工作日；审查 30–60 个工作日；可下载电子证书。
- 加急属第三方服务，非官方通道，学生项目不必。
