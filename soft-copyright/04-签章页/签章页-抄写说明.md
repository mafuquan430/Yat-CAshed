# 签章页：抄写与扫描说明（04-签章页）

## 一、这份文件是什么

官网提交申请并保存后，系统会生成一份《申请确认签章页》PDF。它是**唯一必须手写**的材料：
2026 年起要求申请人本人用黑色签字笔手抄承诺段落、亲笔签名并写身份证号，不得打印名字、
不得代签、不得用电子签名。

本目录不放“可打印的签章页模板”——签章页只能从系统生成（带二维码与受理条码），
自己排版的一律无效。本文件只解决“怎么抄、抄在哪、怎么扫”。

## 二、打印要求

- A4 单面，黑白激光打印即可；
- 打印缩放选 **实际大小 / 100%**，不要“适应纸张”，否则二维码与条码会变形；
- 检查四角定位框完整、条码清晰可扫；
- 打印后不要折叠压在签字区域。

## 三、抄写要求（最容易出错的一步）

1. 用**黑色签字笔**（0.5 mm 左右最稳，太细扫描易断笔，太粗易糊）。
2. 承诺段落**逐字手抄**，不要连笔到无法辨认，不要用行书草书，不要缩写、不要改标点。
3. 签名字段：签**身份证上的姓名**，与“著作权人”完全一致。
4. 身份证号：18 位，逐位写清，不要连笔。
5. 日期：写**实际抄写当天**（与提交日相同或早一天），格式与系统提示一致。
6. 抄错了怎么办：**重新打印一张**，不要涂改、不要用修正带、不要划掉重写。

## 四、抄写时特别注意的承诺要点

签章页承诺段落通常包含以下几类内容（以系统生成的原文为准，此处仅提醒你注意，不要照抄本段）：

- 申请登记的作品由申请人独立开发/合作开发完成；
- 不侵犯他人著作权或其他权利；
- 提交的材料真实、合法；
- **未使用人工智能开发编写代码、撰写文档或生成登记申请材料**；
- 知悉虚假承诺的法律后果。

最后一条与你直接相关：提交的说明书与申请表内容必须是你本人实质性完成并核实的

## 五、扫描要求

| 项目 | 要求 |
|---|---|
| 分辨率 | 300 dpi（低于 200 dpi 条码可能扫不出） |
| 色彩 | 彩色（保留黑色笔迹与蓝色印章的真实颜色） |
| 格式 | PDF 优先；JPG 亦可，但不要多页拼一张 |
| 范围 | 四角完整，含全部条码与定位框，不要裁切 |
| 质量 | 无阴影、无手指、无倾斜（倾斜角 < 2°）、背景接近纯白 |
| 文件名 | `签章页.pdf` |

手机拍摄也可接受，但要用扫描类 App（如系统自带“扫描文档”），不要直接拍照。

## 六、自查（签字后立刻检查）

```
[ ] 承诺段落是手抄，不是打印
[ ] 签名 = 身份证姓名
[ ] 身份证号 18 位完整可辨
[ ] 日期为实际抄写日
[ ] 条码/二维码完整、可扫
[ ] 四角在画面内、无裁切
[ ] 300 dpi、无明显阴影
```
