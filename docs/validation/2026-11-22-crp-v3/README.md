# CRP v3：把模型对回原理文档（2026-11-22）

## 动机

前两轮（P4、P2）都在证明 CRP "不可用"：饱和、空档。但对照原理文档会发现，
问题不只在参数，**实现本身与模型定义有三处偏离**：

| 原理文档的 CRP | 原实现 | 后果 |
|---|---|---|
| 单调递增的**分段线性**剖面（$n$ 段） | 一条直线（0 → 1 ms 线性） | "刚凉"和"凉一半"同斜率，低端没有区分度 |
| 先查 $L_1$，未命中再查 $L_2$、$L_3$ | 三层相加 | 层级语义丢失（$L_3$ 还被写成 $L_2$ 的副本） |
| 找不到前一个实例 ⇒ 未命中 | 找不到记录也返回 0 | **"没跑过的核"被当成"最热的核"** |

第三条最致命：新建作业、历史被裁剪的作业，在所有候选核上都查不到记录，
recency 全 0 → 比率全 0 → benefit 全等于 WCET → 选核完全退化为"第一个候选"。

## 改动

1. **`crp_nohist` 语义**：一个记录都没找到时返回哨兵 `YAT_CRP_NOHIST_NS`，
   比率判为 1000（全冷），并计入 `crp_nohist`。没有历史 ≠ 刚跑过。
2. **分段线性剖面**：五个拐点（0 / 16 µs / 64 µs / 256 µs / 1 ms →
   0 / 100 / 300 / 650 / 1000 千分比），形状按原理文档的"单调、分段线性、
   有限段逼近"，拐点量级取自本轮实测的 recency 分布。
3. **区分度计数器 `crp_split`**：一次决策里，若所有候选核的 crp 相同，
   说明 CRP 这次没起区分作用；不同则计入。这是"CRP 是否真的参与决策"的
   直接读数——比饱和率更贴近"有没有用"。
4. 计数器 33 → **35** 项；文件 2950 → **3018** 行；内核 #28。

## 结果（主口径 3 轮）

| 轮次 | 饱和率 | **区分度** | 接管率 | ρ |
|---|---|---|---|---|
| 1 | 2.7% | 11.2% | 98.1% | 1.779 |
| 2 | 2.8% | 11.7% | 98.4% | 1.911 |
| 3 | 80.6% | 57.1% | 97.7% | 1.910 |

对照（改动前）：

| 版本 | 饱和率 | 接管率 |
|---|---|---|
| P1（原始） | 96.6 / 97.4 / 5.3 | 98.2 / 98.2 / 98.1 |
| P4（归一化） | 81.2 / 0 / 0 / 0 / 82.2 | 98.2 / 98.4 / 98.4 / 98.4 / 98.0 |
| **v3（本次）** | 2.7 / 2.8 / 80.6 | 98.1 / 98.4 / 97.7 |

## 怎么读

1. **低成本，无回归**：ρ 中位 1.91，与 P4 的 1.79、#20 的 1.81 同一区间。
2. **CRP 现在确实参与决策**：区分度 11%–57%，而原实现饱和时这个值恒为 0。
3. **但 QEMU 里不可能有收益**——TCG 没有缓存，CRP 做得再对，墙钟也不会变。
   这正是为什么三处修正后 ρ 没有改善：**不是模型错了，是场地里没有可省的缓存**。
4. 因此 CRP 的收益只能在真机上观测：`pi-2025-07-30` 的 TacleBench 平均轮次用时
   1550.8 → 1413.1 ms（−9.77%，1.108×）是唯一可引用的收益证据。

## 结论（对外口径）

- 在**无缓存**的仿真环境里，CRP 的正确表现就是"没有收益"；把这一点写清楚，
  比在仿真器里编一个缓存收益更诚实，也更能说明真机数据的分量。
- 在**有缓存**的真机上，CRP 的收益是 −9.77%；且模型的三级 recency 与
  分段线性剖面现在与原理文档一致，不再是"一个常数除法"。

## 局限

- 区分度只说明"候选核的 crp 不全相同"，不等于"选中的核因此更好"；
- 拐点取自本轮分布的量级，不是逐级命中率标定；
- QEMU 无法验证收益方向，只有真机能。
